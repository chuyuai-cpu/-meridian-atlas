# 经络寻行 V2 · Meridian Atlas

基于 WebGL / Three.js 的经络穴位教学可视化应用。

## V2 功能

- 十二正经与奇经八脉，共 20 条经脉路径
- 14 条具有独立编号经穴的经脉，显示 WHO 361 经穴总量与结构化重点穴
- 阴经暗色、阳经亮色，经脉独立配色
- 五行穴按木、火、土、金、水五色显示，普通穴为蓝色
- 井、荥、输、经、合、原、络、郗、募、背俞、交会、八脉交会等属性提示
- 三阴交等穴位的多经交会提醒
- 真人比例教学人体、骨骼、五脏六腑、经络、穴位与体内循行分层显隐
- 皮肤半透明 / 透视模式、脏器独立显隐与聚焦
- 粒子、寻迹、脉冲三种循行动画
- 鼠标、触控、捏合缩放与视角预设
- 收藏与进度本地保存
- WebGL 初始化失败时的二维降级提示

## 数据边界

名称、编码、经脉归属与标准定位摘要参考：

- GB/T 12346-2021《经穴名称与定位》
- WHO Standard Acupuncture Point Locations in the Western Pacific Region (2008)
- WHO Standard Acupuncture Nomenclature
- 《黄帝内经·灵枢·经脉》

三维点位、脏器形态和体内循行是教学映射，不用于针刺定位、诊断或治疗。

## 运行

使用任意静态服务器打开项目根目录。页面通过 jsDelivr 加载 Three.js ES Module。
