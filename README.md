# 经络寻行 · 3D Meridian Atlas

一个无需外部运行时依赖的原生 WebGL 经络穴位教学可视化原型，可直接部署到 Vercel。

## 数据与边界

- 穴位编码、名称与定位摘要参考 GB/T 12346-2021《经穴名称与定位》与 WHO/WPRO 361 穴标准。
- 古籍循行节录参考《中国哲学书电子化计划》收录的《黄帝内经·灵枢·经脉》。
- 3D 坐标是按低多边形人体比例建立的教学映射，不可作为针刺定位或诊疗依据。
- “传统应用”“教学配伍”仅用于知识索引，页面内已加入医学安全提示。

## 功能

- 原生 WebGL 低多边形人体、骨骼层、经络层、穴位层
- 三种寻行动画：粒子、逐段寻迹、脉冲
- 鼠标旋转/滚轮缩放，单指旋转/滑动切换，双指旋转/捏合缩放
- 点击与悬停穴位详情、古籍释义、教学配伍
- 收藏、筛选、搜索、进度保存
- WebGL 失败时自动切换 SVG 降级渲染；`?fallback=1` 可主动测试
- 响应式桌面端与移动横屏布局
